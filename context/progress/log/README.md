# log/ — 날짜별 진행 기록

작업 세션이 끝날 때(또는 의미 있는 진전이 있을 때)마다 `YYYY-MM-DD.md` 파일 하나에 짧게 적으세요.
같은 날 여러 번 작업하면 그 파일에 이어서 추가(append)하면 됩니다. 지우거나 고쳐쓰지 말고 계속
쌓아가는 로그입니다 — "왜 이렇게 결정했지?"를 나중에 되짚을 때 씁니다.

## 형식 (권장, 자유롭게 변형 가능)

```markdown
# 2026-08-07

## 오전 (누구/어느 에이전트)
- 한 일: ...
- 결정된 것: ... (있으면 knowledge/decisions.md에도 반영)
- 막힌 것: ...
- 다음: ...
```

작업 끝나면 [`../STATUS.md`](../STATUS.md)의 해당 트랙 행도 같이 갱신하는 걸 잊지 마세요 —
STATUS.md는 "지금 스냅샷", 이 폴더는 "시간순 기록"입니다.
