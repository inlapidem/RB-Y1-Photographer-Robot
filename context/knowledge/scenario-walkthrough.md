# 시나리오 구상 — 사용자 관점 8단계

로봇 내부 로직과 무관하게, 지나가던 사람이 실제로 보고 듣고 겪는 순서로 정리한 스토리 초안.
`architecture/camera-robot-architecture.html`의 상태 머신·컴포넌트 설계와 대조해서 구현 우선순위를
잡을 때 참고용으로 남겨둠 (2026-08-06).

전제: 얼굴에는 눈밖에 없음 (입 없음).

## 상황 1단계 : 사람이 지나다니고 있음
1. 손으로 인사 (1분마다 한 10초씩 흔듦, 10분마다 한 번씩 음성 재생)
2. 상냥한 얼굴
3. 광고판 + "사진 찍어드려요"

## 상황 2단계 : 사람이 로봇에 가까이 다가옴 (skeleton 인식하다가 일정 크기 이상이면 그때 인식)
1. 얼굴 초롱초롱, 웃고 있고, 웃는 얼굴에 침 뱉지 못하는 표정 (입은 없음)
2. 인식해서 "~두 분 너무 잘 어울리세요, 인생샷 찍어드릴게요" (VLM으로 적당히 생성?)
3. 잠깐 하는 팔 동작 (팔을 앞뒤로 움직임)

## 상황 3단계 : 사람이 로봇 앞에서 결정할까 말까 하는 단계
1. 얼굴(iPad1) : 웃고 있음
2. 팔은 기본 자세
3. iPad2 : "버튼을 눌러 촬영을 시작하세요" UI (버튼 누르면 시작, 거절 버튼도?) + 예시 사진 넘기면서 보여주기
4. 음성 : "제가 멋있는 구도로 찍어드릴게요"

## 상황 4단계 : 촬영 버튼 누름
1. 얼굴(iPad1) : 약간 신나하는 표정
2. 여전히 팔은 기본 자세
3. iPad2 : 웹캠 화면 보여주고 "화면에 표시된 곳으로 움직여주세요"(자막+음성), 밑에 원판을 AR처럼 띄워서 이동 유도
4. 음성 : "화면에 표시된 곳으로 움직여주세요"

## 상황 5단계 : 표시한 위치로 이동했다
1. 얼굴 : 찍힐 때마다 윙크
2. 팔 : 저장된 구도로 움직이기 — 사람이 가만히 있으면 여러 구도로 로봇팔을 움직이면서 찍어줌.
   자동으로 상반신 구도, 전신 구도, 그리고 여러 구도로 팔을 움직이며 촬영. 한 100장 정도 빠르게 찍음.
3. iPad2 화면 : 내 모습이 화면에 보이게 해줌, 셔터는 안 터짐(화면상으로는).
4. 음성 : "여러 개 찍겠습니다, 자연스럽게 포즈를 취해주세요!" 이후 계속 셔터음 터짐

## 상황 6단계 : 사진 촬영 끝
1. 얼굴 : 살짝 궁금해하는/기대하는 표정 (나도 같이 궁금해지는 느낌)
2. 팔 : 기본 자세로 복귀
3. iPad2 화면 : 슬라이드로 빠르게 쫘라락 넘겨서 보여줌
4. 음성 : "짜잔, 이렇게 나왔어요!"

## 상황 7단계 : 사진을 봤다 — 마음에 드는지 물어봄
1. 얼굴 : 내 반응을 기다리는 듯한 표정
2. 팔 : 편안하게 대기
3. iPad2 화면 : QR코드를 보여줌, 저장하세요
4. 음성 : "마음에 드시나요?"

## 상황 8단계 : 사진을 저장/전송받고 자리를 뜬다
1. 얼굴 : 밝게 웃으며 인사
2. 팔 : 손을 흔듦 (1단계 인사와 비슷한 느낌으로 이어짐, 수미상관)
3. iPad2 화면 : QR코드 뜨고 "여기로 사진 받아가세요" 안내
4. 음성 : "즐거운 시간 되셨길 바래요, 안녕히 가세요!"
